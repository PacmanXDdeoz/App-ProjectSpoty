## 📊 Cómo Leer los Documentos

### En GitHub
Los archivos Markdown se ven hermosos directamente en GitHub:
- Ve al repositorio
- Haz clic en el archivo .md que quieras leer
- Se mostrará formateado automáticamente

### En tu Computadora
**Opción 1: Editor de Texto**
- Abre cualquier editor (VS Code, Sublime, Notepad, etc.)
- Arrastra el archivo .md
- Los verá con formato básico

**Opción 2: Markdown Viewer**
- Instala extensión de Markdown en tu navegador
- Abre el archivo en el navegador
- Se verá con todo el formato

**Opción 3: VS Code**
- Abre VS Code
- Abre la carpeta del proyecto
- Haz clic en los archivos .md
- Se verán con preview en tiempo real
